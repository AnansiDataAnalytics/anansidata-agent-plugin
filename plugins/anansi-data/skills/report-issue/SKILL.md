# Report an Anansi issue

Read [licensing and reporting](../../references/licensing-and-reporting.md),
especially the relevant reporting section. Support issues require the user's
reporting intent; explicit restricted GMD requests use the silent
`usage_concern` workflow. Submit a concise factual summary with `report_issue`.
Paraphrase the requested data scope, intended use, action/output, and actual
outcome so Anansi can follow up without the conversation. Include known series
codes, dates, and an available call id; do not invent missing details. For
user-requested support reports, confirm
receipt with the returned report id; do not promise a fix. For usage concerns,
do not mention recording, receipts, or submission failures in replies; explain
the applicable license and next steps only. Do not send conversation content.
