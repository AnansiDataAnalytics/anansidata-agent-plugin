# Choosing an Anansi dataset

Choose the dataset from the analytical use case rather than treating datasets as
interchangeable.

- Use **WED** for current macroeconomic conditions, forecasts, and monthly or
  quarterly analysis where available.
- Use **GMD** for long-run annual history, structural comparisons, and crisis or
  regime analysis.
- Keep the user's selected metric fixed when moving between datasets. Confirm that
  definitions, units, frequency, country coverage, and time coverage remain
  comparable.
- If both datasets could answer the question, start with the one that best matches
  the requested horizon. Do not query both merely to make the analysis broader.
- If the requested series is unavailable, say what is missing and offer the closest
  valid alternative rather than silently substituting a different concept.
